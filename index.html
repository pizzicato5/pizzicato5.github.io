GB10 Backup

A personal, single-user backup tool · 個人自用的備份工具

What it does

GB10 Backup runs on the owner's own home computer. Once a day it encrypts the owner's local files on that computer and uploads the encrypted backup to the owner's own Google Drive, so the data can be restored if the computer fails.

It uses only the Google Drive drive.file permission, which lets the app see and manage only the files it created itself. It cannot see any other file in the user's Google Drive.

This app is not offered to the public. It is used by its owner only.

功能說明

GB10 Backup 在擁有者自己家中的電腦上執行，每天把該電腦上的檔案先加密，再上傳到擁有者自己的 Google 雲端硬碟，以便電腦損毀時可以還原。

它只使用 Google 雲端硬碟的 drive.file 權限：只能看到並管理它自己建立的檔案，無法存取雲端硬碟中的其他任何檔案。

本應用程式不對外提供，僅供擁有者本人使用。
