Privacy Policy · 隱私權政策

Last updated: 2026-11-22

Google user data accessed

GB10 Backup requests only the Google Drive drive.file scope. With it, the app can create, read, update and delete only the backup files that it has created itself in the user's Google Drive. It cannot access any other file.

How the data is used

  • The app stores the owner's encrypted backups in the owner's own Google Drive and reads them back only to restore or verify those backups.
  • All backup data is encrypted on the owner's computer before upload, with a password that only the owner holds.
  • No Google user data is sold, shared with, or transferred to any third party, and none is used for advertising or for training AI models.
  • The access token is stored only on the owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions.

Users

This is a personal tool used only by its owner. It is not offered to anyone else.
